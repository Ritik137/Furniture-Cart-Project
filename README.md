# 🪑 WoodenStore (Furniture E-Commerce App)

A full-stack Furniture E-Commerce web application built using **MERN Stack + Microservices Architecture**.

---

## 🚀 Features

- 🔐 User Authentication (Login / Register with JWT)
- 👑 Admin Panel (Add / Delete Products)
- 🛒 Add to Cart functionality
- 🧾 Order system (if added)
- 📸 Image Upload (Cloudinary)
- ⚡ Real-time UI update (Context API)
- 🎨 Modern UI (React + Tailwind)

---

## 🏗️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend (Microservices)
- Node.js
- Express.js
- MongoDB (Mongoose)

### Services
- Auth Service (Port: 5001)
- Product Service (Port: 5002)
- Order Service (Port: 5003)
- Upload Service (Cloudinary) (Port: 5004)


Repeat for:
- product-service
- order-service
- upload-service

---

## 🌐 API Endpoints

### Auth
- POST `/auth/api/register`
- POST `/auth/api/login`

### Product
- GET `/products/api/getall`
- POST `/products/api/add`
- DELETE `/products/api/delete/:id`

### Upload
- POST `/upload/api/post`
